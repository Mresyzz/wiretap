HTTPS 根证书管理

            

            
          


          

            

              WireTap Local Root CA
              X.509 · SHA256
            

            

              
WireTap 基于 Hudsucker 生成本地专有自签根证书。安装并信任该根证书后，即可对局域网与客户端的 HTTPS 流量进行解密审计。

              

                
macOS 信任命令

                
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain wiretap-ca.crt

              

              

                
Windows PowerShell (管理员)

                
Import-Certificate -FilePath ".\wiretap-ca.crt" -CertStoreLocation Cert:\LocalMachine\Root

              

              

                
Linux (Ubuntu / Debian)

                
sudo cp wiretap-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates
